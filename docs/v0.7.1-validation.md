## 一、0.7.0 审查 10 项问题闭环摘要

| 级别 | 审查问题 | 修复方案 | 回归验证 |
| :---: | :--- | :--- | :--- |
| **P1** | 网页版重连可能写错手柄 | 所有板载写操作（`save` / `undo` / `identify` / `recover`）严格绑定成功读取时的完整 `BluetoothDevice.id`，移除唯一授权设备回退，失败读取绝不污染设备缓存 | `test-web-driver.ts` 6.3 通过；原复现断言拦截 |
| **P1** | 网页版 `IndexedDB` 不可用时仍允许写板载 | 分离只读浏览（允许 `kv` 内存回退）与持久化板载事务（`backups` / `journals` 强制要求 `IndexedDB` 成功打开并提交），不可用时在首条 GATT 写入前立即拒绝 | `test-web-driver.ts` 6.5 通过；原复现 0 次写入 |
| **P1** | 合法大键盘宏方案（>256 KiB）重开后显示为空 | 统一读写与导入上限为 `8 MiB`（`MAX_KEYMAP_BYTES`），保存前先校验序列化字节长度；若磁盘旧文件损坏则保留原文件、向界面报告 `load_error`，并在下次覆盖前自动留存备份副本 | `audit_regressions.rs` 与 `test-web-driver.ts` 6.7 通过 |
| **P2** | 两个同源网页标签页可同时通过写入冲突检查 | 基于完整设备 ID 引入跨标签页互斥锁（W3C `navigator.locks` + 模块级锁集合），全程覆盖待恢复检查、回读对比、写入、核对与回滚 | `test-web-driver.ts` 6.4 通过；并发页即时拦截 |
| **P2** | 超出当前编辑范围的旧曲线覆盖后无法撤销或恢复 | 区分用户编辑语义校验（`validate_record`）与经 SHA-256 备份核实的原字节恢复校验（`validate_restore_record`），并在写入前预验证 `undo` / `recovery` 恢复路径 | `audit_regressions.rs` 与 `test-web-driver.ts` 6.1 通过 |
| **P2** | 诊断轨迹写入备份可超 128 KiB 导致恢复列表漏报 | 写前备份剥离 `extra["trace"]`（仅在诊断导出保留），限制会话轨迹上限为 512 帧，并在 `prepare()` 阶段前置执行 `MAX_BACKUP_BYTES` 与 `validate_journal` 自检 | `audit_regressions.rs` 与 `test-web-driver.ts` 6.7 通过 |
| **P2** | WebBLE 请求超时残留等待者吞掉下一条合法响应 | 重构 `WebBleSession.exchange()` 为按序号匹配的在途请求槽位，超时、异常或断开时立即清理定时器与等待状态 | `test-web-driver.ts` 6.6 通过；后续读取正常返回 |
| **P2** | 曲线 `P1=(0,170)` 覆盖原点且死区内预览输出 67%；缺少草稿估算与多手柄槽位说明 | 锁定样条固定端点 `(0,0)` 与 `(255,255)`，约束编辑控制点 `1 ≤ P1.x < P2.x ≤ 254`；死区内预览严格输出 `0%`；界面显式标注“草稿软件估算”并提供多手柄预览槽位切换 | `test-web-driver.ts` 6.2 通过 |
| **P2** | 深色/浅色主要操作与已选胶囊白字对比度低于 4.5:1 | 新增专用高对比宝石蓝填充色阶 `--accent-fill-*`，浅色与深色所有渐变端点与悬停态对 `#ffffff` 对比度均达 `4.77:1 – 8.35:1`（> WCAG AA `4.5:1`） | `test-web-driver.ts` 6.8 自动色度断言通过 |
| **P3** | 构建脚本固定 `0.7.0` 且发布工作流未核对 Git 标签与二进制版本 | `native/build.ps1` 与 `release-desktop.yml` 统一从 `native/Cargo.toml` 解析版本，构建前后自动比对 Git 标签、`tauri.conf.json`、`package.json`、`windows.manifest` 及 `.exe` 的 `FileVersion` / `ProductVersion` | `build.ps1 -ExpectedTag v0.7.1` 校验通过 |
