# O+ Studio 0.6.0 使用指南

Windows 10/11 原生致动 O+ 全系板载配置与电脑键鼠宏工作台（Rust + Tauri 2 + React）。运行 `OPlusStudio.Native.exe` 即可使用，无需安装 Python、Qt 或开启管理员权限。

## 一、快速上手：两种工作模式

O+ Studio 0.6.0 同时提供两类职责清晰的能力，左侧边栏与顶部副标题会明确标示当前模式：

1. **手柄板载配置（需连接蓝牙配置通道）**
   - 包含 **背键工作区**、**手柄设置**、**配置与工具**。
   - 手柄开机并退出手机 KeyLinker App，点击右上角 **“连接并读取”**。
   - 所有板载修改先暂存在草稿中，点击底部 **“保存到手柄 (Ctrl+S)”** 后，程序自动重新读取比对冲突、生成备份、分片写入并逐项回读核对；写入后可一键 **“撤销保存”**。保存完成后可脱离软件随手柄使用。
2. **电脑端键盘宏映射（纯 USB / 2.4G XInput 免蓝牙即用）**
   - 切换至左侧 **“键盘宏映射”**，无需连接蓝牙即可管理方案并开启引擎。
   - 规则修改实时自动保存在电脑本地（`%LOCALAPPDATA%\OPlusStudio\keymap-profiles.json`）；每次启动软件时引擎默认处于关闭状态，需手动点击 **“开启键盘宏引擎”**，且使用期间需保持 O+ Studio 在后台运行。

## 二、背键映射电脑键盘宏（板载暗号桥接）

在标准 XInput 模式下，Windows 只能收到常规手柄按键，无法直接区分独立背键。O+ Studio 通过 **“板载暗号桥接”** 打通实体背键与电脑键盘宏：

1. 在 **“键盘宏映射”** 点击 **“+ 绑定背键（M1–RK）”**，选择要执行的电脑按键或顺序宏（例如 `Space`、`LCtrl + C` 或多步连招）。
2. 系统自动为该背键分配冷门三键暗号（如 `M1 = Back + LS + RS`，若与特定游戏冲突可展开“自定义暗号按键”修改）。
3. 通过蓝牙连接并读取手柄后，点击规则卡片上的 **“同步暗号到背键草稿”**（或顶栏 **“一键同步到背键草稿”**），再点击底部 **“保存到手柄 (Ctrl+S)”** 烧录一次。
4. 此后用 USB 或 2.4G 玩游戏时，开启键盘宏引擎，按下实体背键即可零延迟触发电脑键鼠动作！

### 物理边界说明
- **原生按键透传**：标准用户态 XInput 不会拦截或隐藏手柄自身的按键事件，游戏仍会同时收到暗号所含的手柄按键（因此推荐使用默认三键冷门暗号而非单绑常用正面键）。
- **防串扰独占锁**：按住 `M1` 期间，引擎独占其组成按钮，此时正常推动正面方向键或按键绝不会误触 `M2`；若同时启用了单键规则与包含它的多键规则，引擎自动启用 `20 ms` 前缀防抖，并对 `<20 ms` 的快速轻点在松手时立即补发，不丢轻点。
- **急停与安全保护**：任何时刻按下物理键盘 **`F8`** 立即停止全部循环宏并释放所有模拟按键；进行蓝牙扫描/读写或打开物理按键录入窗口时，键鼠引擎会自动暂停并释放按键。
- **权限与反作弊合规**：软件保持普通用户权限（`asInvoker`）。若目标窗口为管理员运行（触发 Windows UIPI 隔离）或受反作弊保护拒绝 `SendInput`，顶部会弹出可关闭的黄色提示并自动放弃注入，绝不采用驱动或注入手段绕过。

## 三、全系通用化与兼容诊断

- **三级支持状态**：连接蓝牙后右上角显示 **已实测型号**（O+ 1.37）、**动态兼容**（KeyLinker 第二代协议其他固件/4–8 背键型号）或 **只读模式**（第一代协议或未知结构）。
- **按需动态适配**：自动识别 `1–8` 个激活背键槽、每槽步数上限（最高 47 步）、可调振动通道（仅更新实际拖动的通道，保留未触碰通道与关机计时原始字节）、标准改键表（`Back`/`Start` 因固件限制锁定不可设为新改键源，可作为目标）及支持的 RGB 灯区。
- **跨版本配置导入**：支持导入跨固件布局的 `oplus-rear-v1` 背键配置；键盘宏工作区支持直接导入旧版 `0.4.0` 的 `profile.json`。
- **兼容诊断包**：在“配置与工具”（或只读模式主面板）点击 **“导出设备兼容诊断包”**，可保存完整的身份、能力位掩码与原始记录 JSON 以便排查适配。

## 四、外观、高分屏与恢复中心

- 左侧栏支持切换浅色/深色主题与 `100% / 115% / 130% / 150%` 界面字号，窄窗口自动折叠为单列滚动布局。
- 若上次板载保存或背键引导识别因断电/异常中断，`%LOCALAPPDATA%\OPlusStudio\journals` 会保留持久日志；重启软件不会静默自动写入，可在 **“配置与工具 → 恢复中心”** 检查确认后安全恢复。
