# O+ Studio 0.7.4 使用指南

Windows 10/11 原生致动 O+ 全系板载配置与电脑键鼠宏工作台（Rust + Tauri 2 + React）。运行 `OPlusStudio.Native.exe` 即可使用，无需安装 Python、Qt 或内核驱动。

## 一、快速上手：两种工作模式

O+ Studio 0.7.4 同时提供两类职责清晰的能力，左侧边栏与顶部副标题会明确标示当前模式：

1. **手柄板载配置（需连接蓝牙配置通道）**
   - 包含 **背键工作区**、**摇杆与扳机**、**手柄设置**、**配置与工具**。
   - 手柄开机并退出手机 KeyLinker App，点击右上角 **“连接并读取”**。
   - 所有板载修改先暂存在草稿中，点击底部 **“保存到手柄 (Ctrl+S)”** 后，程序自动重新读取比对冲突、生成备份、分片写入并逐项回读核对（弹窗清晰列出如 `左摇杆曲线与死区`、`右扳机曲线与死区`）；写入后可一键 **“撤销保存”**。保存完成后可脱离软件随手柄使用。
2. **电脑端键盘宏映射（纯 USB / 2.4G XInput 免蓝牙即用）**
   - 切换至左侧 **“键盘宏映射”**，无需连接蓝牙即可管理方案并开启引擎。
   - 规则修改实时自动保存在电脑本地（`%LOCALAPPDATA%\OPlusStudio\keymap-profiles.json`）；每次启动软件时引擎默认处于关闭状态，需手动点击 **“开启键盘宏引擎”**，且使用期间需保持 O+ Studio 在后台运行。

## 二、高级摇杆与扳机板载调节

在左侧边栏进入 **“摇杆与扳机”** 工作区，顶部分段切换器可在 **左右摇杆** 与 **左右扳机** 间切换：

1. **交互式单调三次样条响应曲线**：
   - 在 `240×240` 液态玻璃画布上直接拖拽 **P1 / P2** 控制点（或使用下方精确数字框微调），严格锁定固定端点 `(0,0)` 与 `(255,255)` 并约束 `1 ≤ P1.X < P2.X ≤ 254`，曲线采用 Fritsch-Carlson 单调三次样条保证平滑无震荡过冲。
   - 一键选用 **线性默认 · 快速灵敏 · 缓和延迟 · 平滑渐进 · 精细微调** 五大官方曲线预设。
   - 当手柄同时通过 USB / 2.4G 连接电脑时，画布会投射翠绿 **草稿软件估算** 光点（死区内严格归零输出；多手柄同时在线时可在顶栏自由切换预览槽位）。
2. **内外死区联动与扳机四档行程**：
   - **左右摇杆（0–100% 精度）**：独立调节 `中心内死区` 与 `边缘有效上限`（自动计算外死区边距并防交叉越界），支持切换 **X 轴反向**、**Y 轴反向** 与 **左右摇杆互换**（常规互换建议左右摇杆同步开启）。
   - **左右扳机（0–200 精度）**：内置 **零死区全行程（0–200）**、**微死区灵巧（4–166）**、**中行程均衡（20–160）**、**短触发速射（30–140）** 四档快捷行程，也可手动微调起始死区与满行程触发点。
   - 支持点击 **“复制到右摇杆 / 左摇杆”**（或复制到对侧扳机）一键镜像参数，未触碰通道与未知标志位 `100%` 原样保留。

## 三、背键映射电脑键盘宏（板载暗号桥接）

在标准 XInput 模式下，Windows 只能收到常规手柄按键，无法直接区分独立背键。O+ Studio 通过 **“板载暗号桥接”** 打通实体背键与电脑键盘宏：

1. 在 **“键盘宏映射”** 点击 **“+ 绑定背键（M1–RK）”**，选择要执行的电脑按键或顺序宏（例如 `Space`、`LCtrl + C` 或多步连招）。
2. 系统自动为该背键分配冷门三键暗号（如 `M1 = Back + LS + RS`，若与特定游戏冲突可展开“自定义暗号按键”修改）。
3. 通过蓝牙连接并读取手柄后，点击规则卡片上的 **“同步暗号到背键草稿”**（或顶栏 **“一键同步到背键草稿”**），再点击底部 **“保存到手柄 (Ctrl+S)”** 烧录一次。
4. 此后用 USB 或 2.4G 玩游戏时，开启键盘宏引擎，按下实体背键即可零延迟触发电脑键鼠动作！

### 物理边界说明
- **原生按键透传**：标准用户态 XInput 不会拦截或隐藏手柄自身的按键事件，游戏仍会同时收到暗号所含的手柄按键（因此推荐使用默认三键冷门暗号而非单绑常用正面键）。
- **防串扰独占锁**：按住 `M1` 期间，引擎独占其组成按钮，此时正常推动正面方向键或按键绝不会误触 `M2`；若同时启用了单键规则与包含它的多键规则，引擎自动启用 `20 ms` 前缀防抖，并对 `<20 ms` 的快速轻点在松手时立即补发，不丢轻点。
- **急停与安全保护**：任何时刻按下物理键盘 **`F8`** 立即停止全部循环宏并释放所有模拟按键；进行蓝牙扫描/读写或打开物理按键录入窗口时，键鼠引擎会自动暂停并释放按键。
- **管理员权限与反作弊合规**：软件默认以普通用户权限启动。若遇到记事本内能打出按键、切进游戏却无反应（游戏或启动器以管理员身份运行触发 Windows UIPI 隔离），先退出本软件，右键 `OPlusStudio.Native.exe` 选择 **“以管理员身份运行”** 再开启开关即可生效；遇到内核级反作弊保护拒绝 `SendInput` 时，程序会自动放弃注入并提示。

## 四、全系通用化、外观与恢复中心

- **三级支持状态**：连接蓝牙后右上角显示 **已实测型号**（O+ 1.37）、**动态兼容**（KeyLinker 第二代协议其他固件/4–8 背键型号）或 **只读模式**（第一代协议或未知结构，支持一键导出 `oplus-diagnostic-v1` 诊断包）。
- **外观与高分屏**：左侧栏支持切换浅色/深色主题与 `100% / 115% / 130% / 150%` 界面字号，窄窗口自动折叠为单列滚动布局。
- **恢复中心**：若上次板载保存或背键引导识别因断电/异常中断，`%LOCALAPPDATA%\OPlusStudio\journals` 会保留持久日志；重启软件不会静默自动写入，可在 **“配置与工具 → 恢复中心”** 检查确认后安全恢复。
- **免登录问题反馈**：点击左下角 **“问题反馈 · 免登录”** 或在 **“配置与工具”** 页面提交反馈，无需 GitHub 账号即可一键上传问题现象与手柄兼容诊断快照。
