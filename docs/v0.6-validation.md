## 三、证据与物理边界说明

1. **XInput 原生按键透传边界**：软件采用纯用户态 XInput 读取与 `SendInput` 模拟，不安装虚拟手柄内核驱动（如 HidHide/ViGEm），因此游戏会同时收到暗号所含的原生手柄输入。三键冷门暗号预设与组合键独占锁最大限度降低游戏内误触，但并非底层驱动级输入屏蔽。
2. **UIPI 与反作弊合规边界**：程序保持 `asInvoker` 标准用户权限。若前台窗口以管理员权限运行（触发 Windows UIPI 隔离）或受内核级反作弊保护拦截 `SendInput`，注入会返回 `0`，引擎立即放弃并在顶部展示可关闭的提示条，绝不执行提权或跨进程注入绕过。
3. **动态兼容型号边界**：非 `1.37` 的 KeyLinker Gen2 致动手柄基于协议自描述能力表提供了完整的读写、校验与回滚保护，但本轮物理实机闭环仅在当前连接的 `1005:2001` 固件 `1.37` 实机上执行；其他批次实机首次连接建议先导出完整原始快照备份并通过“引导识别”核对背键丝印顺序。
