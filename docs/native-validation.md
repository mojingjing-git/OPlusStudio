- 独立计划审查与实施审查及处理记录已落盘，分别见 `docs/rust-migration-review.md`、`docs/rust-implementation-review.md`。

## 实机验证

- Rust 原生读取成功，不启动 Python/Qt/HTTP 配置服务。完整身份与宏布局符合预期。
- 五项可逆操作：M1 临时映射 A、M2 写入 18 字节多分片宏、电机单字节变化、R3→L3 标准改键、RGB 单字节变化。每项写入后回读，再以独立事务撤销。最后所有原始记录逐字节一致。证据：`reports/rust-device-roundtrip-final.json`。
- 本轮测试开始时，M1/M2/LM/RM 与较早 0.4.0 备份已经不同。测试保留的是本轮开始的实际配置，没有覆盖为旧备份。
- 实际桌面预览与最终发布程序均验证：读取 → M1 按住 A 草稿 → 保存清单 → 保存并核对 → 撤销并核对。预览还验证重启后恢复本地草稿。
- 桌面 UI 检查 100% / 150% 字号、深浅主题，以及约 930 像素宽窗口与 150% 字号组合：编辑区上下布局，内容可滚动，保存栏可见，没有观察到横向溢出。
- 最终发布包进入六键识别采样后关闭窗口：窗口先显示等待恢复，再退出。四个实际改动的记录均在持久日志中标记 restored；另外两项原值已与临时标记相同，无需写入。退出后原生独立读取确认六背键及全部设置与测试前逐字节一致。证据：`reports/native-release-gui-validation.json` 与 `reports/native-release-final-restored.json`。

## 证据边界

字体缩放检查与 PE 清单检查不等于跨不同 DPI 的实体显示器拖动测试。本轮未宣称完成该物理场景。

宏与 RGB/电机检查验证了编码、保存、回读与恢复；没有声称验证全部实体灯效、振动效果、宏物理时序。六个背键独立映射电脑键仍是第二阶段。

程序故障模拟不是实际断电试验；磁盘写入使用文件同步及 Windows 原子替换，但不保证硬件不遵守刷盘请求时仍绝对持久。已知旧版进程检查也不代表所有第三方应用都参与互斥。
