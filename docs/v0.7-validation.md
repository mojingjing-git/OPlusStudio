## 二、协议与物理边界说明

1. **曲线插值说明**：协议在手柄板载存储 `P1 (x1, y1)` 与 `P2 (x2, y2)` 两个精确控制点（`0–255` 坐标系）；界面绘制采用单调三次 Hermite 样条（Fritsch-Carlson 切线，无过冲、不回折）忠实呈现控制点走向，芯片内部具体分段/样条算术以硬件实际固件实现为准。
2. **实机待机说明**：因先前预检读取确认该手柄板载无操作自动休眠定时为 `15` 分钟（`motors` 尾部 `20 bf 02 00` = `180,000` ticks），在 `0.7.0` 编译完成时刻手柄已进入省电休眠；`probe roundtrip07` 可逆实机往返命令已就绪，唤醒手柄后可随时执行实机单字节修改与撤销校验。
